# movie-ticket-booking
# Movie Ticket Script

This Python script is an interactive program that helps users choose a movie genre and calculates the ticket price based on their age.

## Features

- Greets the user by name.
- Asks if the user wants to watch a movie.
- Allows the user to select their favorite movie genre (action, comedy, or drama).
- Suggests a movie based on the selected genre.
- Calculates the ticket price based on the user's age:
  - Free for children under 3 years old.
  - $10 for children aged 3 to 12.
  - $15 for adults aged 13 to 60.
  - $12 for seniors over 60.
